# Flame and Blame — чернетка для здачі

## Де допоміг AI (чернетка, 6 речень)

Увесь код і генератори сцени написані в парі з Claude Code: я ставив задачу модулем (фундамент, шланг, вогонь, вина, UI),
а AI пропонував план файлів і писав реалізацію за правилами з `CLAUDE.md`. Найбільше часу AI зекономив на рутині, яку
інакше робиш руками в редакторі: квартира, префаби, матеріали, текстури й навіть шрифт з кирилицею генеруються однією
кнопкою Build All. Компіляцію, збірку сцени, валідацію Zenject і headless-прогін білду AI запускав сам у batchmode і
виправляв помилки до того, як я відкривав Unity. Мої рішення — що смішно, що вирізати, як має відчуватися віддача, і
тестування руками в Play Mode, після якого ми разом підкручували шланг і колізії. AI також допоміг утримати архітектуру
чистою в умовах двох днів: DI, сигнали, пули, MVP і Strategy з'явилися не «для галочки», а як найпростіший спосіб
змусити системи впливати одна на одну.

## Чому ця фіча — «ланцюжок вини» (чернетка, 6 речень)

Тема конкурсу — «Flame and Blame», тож я хотів, щоб вина була не текстом у кінці, а механікою, яка працює в кожен момент.
Кожна дія в грі пам'ятає свою причину: вода — тебе, калюжа — воду, удар струмом — калюжу і стару проводку одночасно.
Через це гра сама розповідає історію: у стрічці справа видно, як твій героїзм перетворюється на рахунок, а у фіналі —
хто насправді винен і на скільки відсотків. Найсмішніші моменти виникають самі: ти гасиш диван, заливаєш телевізор,
стаєш у воду, що вже дійшла до подовжувача, — і вердикт каже, що 100% вини твої. Це добре читається з першого погляду на відео і чесно показує
взаємодію систем: фізика шланга, вогонь, вода, струм і UI говорять через один граф причин. А для коду це гарна
демонстрація: нова система автоматично отримує правильну вину, якщо просто передає Cause.

| Час | Що показуємо | Що говоримо / титри |

| 0:15–0:50 | Вогонь іде сковорідка → шафки → штора → диван; стрічка вини справа | «Кожна подія пам'ятає, хто її спричинив» |
| 0:50–1:30 | Шланг: набір тиску, FOV-кік, віддача відкидає назад, стільці й тарілки летять, шланг волочиться | Фізика шланга, крива тиску |
| 1:30–2:10 | Гасіння: пара, мокрі предмети темнішають; полити телевізор → іскри, «Струм оцінив» | Правила взаємодії (Strategy) |
| 2:10–2:50 | Струмінь пожежного рукава, вода розтікається калюжами й обтікає меблі, калюжа доходить до подовжувача — світиться під струмом, удар, hit-stop + слоу-мо | Фізика калюж; удар має два «батьки» в графі |
| 2:50–3:10 | F1 debug-оверлей: ланцюжок `(Ти → HoseSpray → Puddle + Стара проводка → FaultyWiring) → Electrocution → Ти`, 50/50 | Як рахується вина |
| 3:10–3:25 | Рубильник у тамбурі (E) вимикає струм | Системи впливають одна на одну |
| 3:25–4:05 | Рахунок за виклик: лічильники, топ-3 ланцюжки, печатка «Винен: Ти (63%)» | Фінал і вердикт |
| 4:05–4:40 | Архітектура: схема з `ARCHITECTURE.md`, Build All генерує квартиру | DI, сигнали, пули, MVP, процедурні ассети |
| 4:40–5:00 | Рестарт R, інший сценарій — інший вердикт; посилання на itch.io | Заклик зіграти |

Порада для запису: перед зйомкою закрити Debug-оверлей, писати в 1920×1080, 60 FPS; кілька дублів удару струмом.

## Деплой на itch.io (HTML5)

1. Unity Hub → Installs → 6000.3.11f1 → Add modules → **WebGL Build Support**.
2. У Unity: `Tools/Flame&Blame/Build All`, потім `Tools/Flame&Blame/Build WebGL` (ставить Gzip + Decompression Fallback,
   Minimal stripping). Результат — папка `Builds/WebGL` (`index.html`, `Build/`, `TemplateData/`).
3. Перевірити локально: Unity → File → Build Profiles → WebGL → *Build And Run* (або будь-який локальний сервер);
   `index.html` з диска напряму не відкривається.
4. Запакувати **вміст** `Builds/WebGL` у zip так, щоб `index.html` був у корені архіву.
5. itch.io → Upload new project:
   - Kind of project: **HTML**; завантажити zip, позначити *This file will be played in the browser*.
   - Viewport: **1280 × 720** (або 1920 × 1080), увімкнути **Fullscreen button**.
   - Увімкнути *SharedArrayBuffer support* не потрібно.
   - Visibility: Draft → перевірити гру на сторінці → Public (або Restricted для журі).
6. Якщо браузер пише про `Content-Encoding`: Decompression Fallback уже ввімкнений, тож перевірте, що в zip саме
   файли білду без зайвої вкладеної папки.
7. Запасний варіант: `Tools/Flame&Blame/Build Windows (fallback)` → zip `Builds/Windows` як Windows-завантаження.

Керування для сторінки гри: ЛКМ — шланг (тримай для тиску), WASD — рух, миша — огляд, Space — стрибок,
E — рубильник, R — рестарт, F1 / ` — ланцюжок вини (debug), Esc — відпустити курсор.
